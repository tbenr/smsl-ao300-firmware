SMSL AO300 · custom firmware designsUI Themes

Each theme restyles the two screens the stock firmware shows most, and the way it moves between them: a home screen with the same information as today, and a volume screen that takes over when you turn the knob and goes back home 2 s after the last step. Menus and the standby screen stay stock. Each theme is drawn at the panel's size, one canvas pixel per LCD pixel, and tints itself with the colour picked in the amp's COLOR menu (the COLOR tint below). Transitions are limited to wipes and reveals, because this panel can only afford to repaint the whole screen about once per transition.

Why only wipes and reveals: there is no framebuffer and the stock driver needs about 3 µs a pixel. A wipe, sweep, iris or blind paints each pixel once, so a whole transition costs one screen: about 163 ms with the stock driver and about 44 ms with the fast pixel path verified in features/blit-test and used by features/fast-lcd. A crossfade or slide repaints the full screen every frame, which this panel cannot do smoothly. The one exception here is Phosphor Panel, which only fades the lit areas.

dB values are relative to step 60, taken from the stock volume table at 0x9289. Pixel counts and flash sizes are estimates. The Bluetooth home label and the timer tick length have not been traced in the code; 2 s is an assumed value for the 200 ticks.

Keys: ↑ ↓ change volume, M mutes, when no control has focus.
